Paste customer comments in Algerian Darija, Arabic, French or English and get negative, neutral or positive for each one.

The model, [okba-bouziane/dzsentiment-xlmr-base](https://huggingface.co/okba-bouziane/dzsentiment-xlmr-base), runs in your browser: XLM-RoBERTa base fine-tuned on 45,516 labelled comments and tweets, quantised to 8 bits (about 280 MB, downloaded once). Comments never leave the device. Code and evaluation: https://github.com/okba-bouziane/DzSentiment
